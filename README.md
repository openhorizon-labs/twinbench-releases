# TwinBench releases

Installers for the TwinBench desktop app, and the files the app reads to update itself.

- macOS (Apple silicon): `.dmg`
- Windows (x64): `.exe`
- Linux (x64): `.AppImage` or `.deb`

Download the latest from the [releases page](https://github.com/openhorizon-labs/twinbench-releases/releases/latest).

This repository holds built installers only. It has no source code.
